# Ocaris — Orações Eucarísticas

Aplicação web moderna, responsiva e rápida desenvolvida em **React** com **Vite** e **Tailwind CSS**, contendo todas as Orações Eucarísticas do Missal Romano, o Rito da Comunhão, os Ritos Finais e a liturgia diária consultada por data.

---

## ✨ Funcionalidades

* 📖 **Todas as Orações Eucarísticas (I a XI):**
  * Orações Principais (I a V)
  * Diversas Circunstâncias (VI-A, VI-B, VI-C, VI-D)
  * Reconciliação (VII e VIII)
  * Crianças (IX, X e XI)
* 🍞 **Rito da Comunhão:** Pai-Nosso, Oração pela Paz, Cordeiro de Deus e Comunhão.
* ✨ **Ritos Finais:** Bênçãos Solenes (Tempo Comum I e II, Tempo Pascal III).
* 📅 **Liturgia do dia:** consulta por data com Orações da Coleta, sobre as Oferendas e após a Comunhão, Primeira e Segunda Leituras, Salmo e Evangelho, via API pública Liturgia.
* 🔍 **Busca Instantânea:** Filtro em tempo real por título, número, categoria ou trecho do texto litúrgico.
* 🎛️ **Painel de Preferências de Leitura:**
  * **Temas:** Modo Claro, Noturno (Escuro) e Sépia (Leitura suave).
  * **Zoom de Fonte:** Ajuste dinâmico do tamanho do texto (14px a 34px).
  * **Tipografia:** Alternância entre fonte Serifada (litúrgica tradicional) e Sem Serifa (moderna).
  * **Alinhamento:** Justificado ou Alinhado à esquerda.
  * **Destaque Litúrgico:** Realce visual para as respostas da assembleia (**T:**) e falas do sacerdote (**PE:**).
  * Persistência automática das configurações no navegador (`localStorage`).
* 📱 **Mobile-first:** Design fluido e responsivo otimizado para celulares, tablets e desktops.

## 🚀 Como Executar Localmente

### Pré-requisitos
* **Node.js** (v18+)
* **npm** ou **yarn** / **pnpm**

### Instalação e Desenvolvimento
```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev
```
Acesse no navegador: `http://localhost:5173`
